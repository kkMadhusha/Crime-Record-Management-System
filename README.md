# Crime Record Management System (CRMS)

A Java-based console application developed to manage crime-related records and support basic crime case management activities.

## Features

- Manage criminal person records
- Add and view criminal history
- Search criminal persons by National ID
- Register and search crime incidents
- Assign police officers to crime cases
- Track case progress
- Generate crime reports
- Manage crime categories
- Manage court cases and verdicts
- Manage investigators and assigned cases
- Add, update, view, and delete suspects
- Manage witness and evidence information
- Basic file handling for crime descriptions

## Object-Oriented Programming Concepts

This project demonstrates the following OOP concepts:

- **Encapsulation** – Private fields with public methods for controlled access
- **Inheritance** – Classes extending other classes to reuse functionality
- **Abstraction** – Abstract classes and abstract methods
- **Polymorphism** – Overriding methods in subclasses

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure Java is installed and configured.
3. Open CRMSApplication.java.
4. Run the main() method.
5. Use the console menu to interact with the system.

## Data Storage

This project uses in-memory Java objects and collections for storing data during program execution. It does not use a database.

## Project Type

This is an academic Java/OOP console application developed as a university project.
